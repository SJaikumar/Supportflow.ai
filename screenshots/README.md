# Screenshots — Add Images Before Submission

**No evidence screenshots are included automatically.** Please run the app locally and capture actual final UI states. Suggested filenames:

| Filename | What to capture |
| --- | --- |
| `01_resolved_ticket.png` | A ticket marked Resolved and the final customer reply |
| `02_escalated_ticket.png` | A billing/payment dispute, High priority and escalation reason |
| `03_ticket_log.png` | Support tickets/log table with export button or downloaded log |
| `04_human_approval.png` | Approver reviewing/editing or deciding on a proposed refund |
| `05_ai_analysis_citations.png` | AI-generated reply and grounded policy citations |
| `06_customer_portal.png` | Customer dashboard with recent requests (optional) |
| `07_escalation_assignment.png` | Alex assigns to Maya and the active escalation appears (recommended) |
| `08_closed_ticket.png` | Manually resolved/closed ticket (recommended) |

Use Windows Snipping Tool (`Win + Shift + S`) or another screenshot utility. Crop out browser tabs containing personal information and never show an API key or real credentials.

Once saved, place the PNG files inside this `screenshots/` folder; GitHub will show them in the repository. You can embed them in `README.md` using:

```markdown
![Resolved ticket](screenshots/01_resolved_ticket.png)
```

For the assignment, include at least one **Resolved**, one **Escalated** and a **Ticket Log**, plus two of your own test cases.
